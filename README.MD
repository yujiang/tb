# 前言

tb = turnbase 回合制
做了十多年的回合制游戏， 战斗最耗费时间，不仅是开发还是测试。
所以先把战斗一块单独提炼出做成库，不包括显示部分，那么就可以单独制作并测试战斗逻辑了。

# 内容
抽象的战斗逻辑

这个很难：
数值：多种比如显示条：血，血+蓝，血+防
指令：下了一个单位的指令立即动，一起下完所有单位的指令再动...
次数：有的一个单位一回合只能动一次，有的用速度条可以动多次（全部动过了一次算1回合）
同时支持单机和网络游戏。

有的需要使用者自己去实现，比如数值的不同，你不可能囊括。
但是机制可以内置常用的几套，使用者自己配置一下即可。

1. tb库
    1. Object：战斗单位，技能，buff
    2. 空间：战场站位，阵法
    3. 时机：回合前，出手前，命中，加血，受伤，死亡，回合后，胜负...
    4. AI：普通怪的AI, 简单AI（随机打，打最弱的，加血最少的），BOSSAI, 玩家自动=简单AI
    5. 战斗逻辑：胜负判定，回合，多波敌人，暂停插入对话，记录录像

2. 一个最简单的示例（数值只有：攻击+防御+血）

3. 一个命令行的编辑器（方便制作和测试）
    调出战斗
    下指令
    查看战场，单位，单位的buff
    记录log和录像

4. 数据驱动（表格管理）

# 当前实现

已提供独立 TypeScript 战斗库，以及仅有攻击、防御、生命的可运行示例。核心无运行时第三方依赖，不依赖网络、显示、系统时间或 Node API。

- 双阵营、固定槽位，每轮收齐所有指令后按单位初始顺序行动。
- 单位与技能定义/实例分离；自定义资源、目标规则、效果执行器、死亡和胜负规则。
- 普通攻击、待机、死亡取消后续行动、失效目标检查、最大轮数判平。
- 确定性随机数、指令幂等、带因果关系的事件、受限反应效果队列。
- JSON 快照恢复、输入记录导出、录像重算及最终状态比对。
- 无网络的确定性 AI 示例、文字战报与 JSON 事件输出。

Buff、通用触发窗口、费用/冷却、其他回合策略、多波和剧情暂停依照设计放在后续阶段；命令行编辑器、表格导入也尚未实现。

# 运行

需要 Node.js 22 或更高版本以及 npm。

```sh
npm ci
npm test
npm run example
```

`npm run build` 生成 `lib/` 内的 JavaScript、类型声明和 source map。示例先输出文字战报，再输出 JSON 事件，并自动用记录重算校验。

预期战报：

```text
第 1 轮
  A → B：伤害 3，实际扣血 3，剩余生命 5
  B → A：伤害 3，实际扣血 3，剩余生命 7
第 2 轮
  A → B：伤害 3，实际扣血 3，剩余生命 2
  B → A：伤害 3，实际扣血 3，剩余生命 4
第 3 轮
  A → B：伤害 3，实际扣血 2，剩余生命 0
  B 死亡
胜方：A（elimination）
录像重算校验：通过
```

接口与接入示例见 [API.md](./API.md)。最小规则、配置和驱动分别位于 `examples/simple/rules.ts`、`definitions.ts` 和 `run.ts`。
