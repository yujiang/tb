# buff 特殊类型

### 不屈
如果要死亡，hp=>1

### 反射
默认反射魔法伤害给攻击者，治疗转移给随机存活敌人；自身不承受已转移的效果。

### 嘲讽
挂在被嘲讽者身上，施加者是被强制选择的目标。
当施展一个对象是敌方的技能时，自动把主目标变为嘲讽者，而不是禁止他。

### 休息
休息由 `status: ["休息"]` 表达，通过状态表的 `action` 限制跳过主动行动，Buff 和被动共用判断。`class: "rest"` 只作旧配置兼容；持续时间仍由 turnType/lastTurn 决定。

### 自动复活
真实死亡后按自身最大生命比例复活，触发一次就消失。

### 保护
A保护B，保护必然在本回合第一个出手，跟B加保护buff
B一旦被人伤害：不是buff，不是反伤，不是分担（A保护B，B又保护A，就死循环了）；A都跳出来为他分担一半伤害。
后续B吸血，反伤按照分担后的一半来计算。
