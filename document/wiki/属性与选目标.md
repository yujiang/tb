## FightAttr：单位完整属性

除写明缺省的字段外，宿主应提供完整结构。技能/Buff 里的 `Partial` 是属性增量，不能拿它替代单位基础属性。

| 字段 | 含义 | 缺省、边界与用途 |
| --- | --- | --- |
| `point` | HP/MP/SP/JP 四槽资源结构 | 必填，见 PointAttr；宿主决定显示哪些资源条 |
| `grade` | 单位等级 | 逃跑时与 FightData.runawayGrade 比较，未提供按 0；与技能等级独立 |
| `damageLimit` | 本单位每次造成伤害的生命点数上限 | 非负有限数，如 9999；默认 0 或省略不限制，正数按伤害规则向下取整。读取实际来源的当前 attr，可被 Buff/被动修正；与调试限伤同时开启时取较小值 |
| `speed` | 基础速度 | 必填；普通行动排序还计初始化乱敏 |
| `jpAdd` | 每次有效行动条推进增加的集气 | 创建属性时取 fightConsts.jpAdd，初始 1；可被 Buff/被动修正 |
| `spHurtRate` | 每点实际受伤增加的怒气倍率 | 创建属性时取 fightConsts.spHurtRate，初始 0；可被 Buff/被动修正 |
| `spOutputRate` | 每点实际伤害或治疗增加的怒气倍率 | 创建属性时取 fightConsts.spOutputRate，初始 0；可被 Buff/被动修正 |
| `weapon` | 服务端兵器类型 | 使用 WeaponEnum；用于 NPC 兵器弱点匹配 |
| `career` | 职业数值 | 使用 CarerrEnum 或宿主扩展值；医生 AI 比较 `CarerrEnum.医生` |
| `charProp` | 人物五行 | 缺省 none；受伤相克、治疗相生及治疗施放属性的缺省来源 |
| `weaponProp` | 武器五行 | 缺省 none；技能未覆盖时供攻击/毒伤使用 |
| `weakProp` | NPC 五行弱点列表 | 可省略；任一弱点列表已配置就替代受伤相克；空数组表示此类无弱点 |
| `weakWeapon` | NPC 兵器弱点列表 | 可省略；五行/兵器任一命中只加一次 0.5，不叠加命中个数 |
| `shield` | NPC 弱点盾格数 | undefined 不启用；attrOri 保存回满值，attr 保存当前格数；0 时眩晕 |
| `physic` | 物理各阶段属性 | 完整 FightTypeAttr |
| `magic` | 魔法各阶段属性 | 完整 FightTypeAttr |
| `heal` | 治疗公式属性 | BaseAttack，不是分阶段 FightTypeAttr |
| `poison` | 毒伤公式属性 | BaseAttack；其中 hurt/hurtAnti 的量纲与普通伤害不同 |

### PointAttr

| 字段 | 含义 | 使用规则 |
| --- | --- | --- |
| `hp` | 当前生命点数 | 伤害按实际扣血，不扣成负数 |
| `hpMax` | 最大生命点数 | 治疗/复活上限；血线使用 hp/hpMax |
| `mp` | 当前法力点数 | 可刚好支付到 0；怪物当前不耗资源 |
| `mpMax` | 最大法力点数 | 宿主提供，当前没有通用自动回蓝 |
| `sp` | 当前怒气点数 | 省略初始化为 0，可与其他三槽同时存在 |
| `spMax` | 怒气上限 | 非负有限数，省略为 0，不积累怒气 |
| `jp` | 当前集气点数 | 省略初始化为 0，与 MP 独立存在；仅全局 jiqi 开启时结算并发送客户端 |
| `jpMax` | 集气上限 | 非负有限数，省略为 0，不积累集气；全局 jiqi 关闭时初始化不发送 |

SP/JP 新字段可省略，单位内部仍保留四槽；全局 `jiqi` 未开启时初始化不发送 `jp/jpMax`，不计算行动后的集气，`addJp` 直接返回 0，JP 费用不检查、不扣除，也不发送集气增减消息。其他资源照常处理。开启时恢复原有集气结算和同步。宿主显式提供当前值时保留，不在 `startFight` 时强制归零；关闭开关也不清空内部集气。当前资源在属性重算时保留，不回填或修改 `attrOri`。资源增长保留小数，按各自上限截断。

### FightAttr：资源增长属性与 FightUnit 入口

以下字段属于 `FightAttr`，不再直接放在 `FightUnit` 上。创建基础属性时从 [fightConsts](./战斗常量.md) 读取默认值；单位持有 `attrOri` 基础值及 `attr` 当前值。Buff/被动通过 `attr/attrLevel` 修正，运行时增长统一读取当前 `unit.attr`。之后更新公共默认值不会修改已有属性。需要永久覆盖单位基础值时修改 `unit.attrOri` 并调用 `calcAttr()`，不要通过改基础值模拟临时 Buff。

| 字段 | 默认值 | 用途、单位与范围 |
| --- | --- | --- |
| `jpAdd` | 取创建属性时的 `fightConsts.jpAdd`，初始 1 | 每次行动条推进时，该单位增加的集气点数，可含小数 |
| `spHurtRate` | 取创建属性时的 `fightConsts.spHurtRate`，初始 0 | 每点实际受伤获得的怒气；例如 0.2 表示实际受伤 100 点增加 20 怒气 |
| `spOutputRate` | 取创建属性时的 `fightConsts.spOutputRate`，初始 0 | 每点实际输出伤害或实际治疗获得的怒气；伤害、治疗使用同一个倍率 |

公共属性使用 `CommonAttr` 类型供 Buff/被动配置：`attr` 固定增加值加 `attrLevel × 等级`。支持速度、damageLimit 与以上三个增长属性，合并后 damageLimit 和增长属性最低为 0，damageLimit 为 0 表示不限伤。属性重算不修改 `attrOri`，也不清空当前资源。

`damageLimit` 是来源单位的输出上限，不是自身受伤上限。普攻、技能及各段连击/连招、溅射、追击、协战、反击和其他公共 onHurt 来源，每次都读取实际伤害来源的 `attr.damageLimit`；例如反伤读取反伤者，而不是上下文根攻击者。防御/盾减伤后、beforeHurt 前限伤，保护分担限伤后的伤害，不屈按限伤后是否致命判断；最终扣血也再次受限，并遵守 minHp。与 `getDebugHurtHpLimit()` 同时启用时取较小的正数上限，返回值、消息、事件、仇恨、贡献、怒气及后续吸血/反伤都使用实际扣血。治疗及 HP 费用不受影响。

`addMp(amount, ctx)`、`addSp(amount, ctx)`、`addJp(amount, ctx)` 返回实际增加量，并同步客户端。增长量为零或无效时不发送消息。怒气使用实际生命变化，过量伤害与溢出治疗不计；取消的原伤害不计，自身扣血的技能费用不计。对自己造成伤害不再给自己额外计算输出怒气，自疗按实际治疗计入输出怒气。反射、反伤、保护分担和周期伤害在公共受伤入口按真实伤害来源结算。

单位 `minHp` 是运行时锁血下限，默认 0，不属于 `FightAttr` 或表格配置。伤害在扣血前按当前可扣生命截断；`onHurt` 返回值、`hurt` 消息及事件、仇恨、阵营贡献、怒气、吸血、反伤和连招累计统一读取实际扣血。当前生命已达到或低于锁血线时实际伤害为 0，受伤不会把生命抬到锁血线。保护双方分别应用自己的下限，未扣掉的分担伤害不转回主目标；主目标后续吸血和反伤不包含保护者实际扣血。

仅在全局 `jiqi: true` 时，普通行动条单位行动及 Boss `extraAction` 完整执行后，为所有当前存活单位分别增加自身的 `jpAdd`。防御也算行动；死亡、动作被禁止或费用不足等未实际执行的机会不增加。规则插入技能、烟雨即时技能、破盾大招、连击/连招/反击/协战/溅射不单独推动集气。直接调用 `Fight.processUnit` 只结算行动，不消费行动条，因此不增加集气。

### FightTypeAttr

| 字段 | 含义 |
| --- | --- |
| `base` | 普攻、主攻击的 BaseAttack |
| `kill` | 击杀追击的 BaseAttack |
| `next` | 连击与连招的 BaseAttack |
| `spread` | 溅射的 BaseAttack，不存在自动固定七折的通用规则 |
| `fback` | 反击的 BaseAttack；受伤规则的新攻击使用基础攻击而不是此组 |
| `final` | 本物理/魔法组共用的 FinalAttack |

这些阶段不会自动把 base 复制过去；模板需明确提供。配置子技能再与对应阶段属性合并。

### BaseAttack

| 字段 | 含义与单位 | 计算注意 |
| --- | --- | --- |
| `rand` | 内置连击/追击/反击概率，0～1 | 主动技能发动取 SkillData.rand |
| `hit` | 物理命中点数，例如 100 | 与目标 dodge 相减后除以 100 |
| `dodge` | 物理闪避点数，例如 20 | 禁止 dodge 时直接命中，不抽样 |
| `attack` | 攻击数值 | attackRate 只缩放单位来源的这一项 |
| `defend` | 对应分组的防御数值 | 参与 attack-defend |
| `hurt` | 普通攻击/治疗中的固定增加值 | 毒公式中改为目标当前生命比例 |
| `hurtP` | 普通公式比例加成，例如 0.2 | 先减 hurtPAnti，下限 0；毒公式不读取 |
| `hurtAnti` | 抵消施放方 hurt | 普通公式是固定量，毒公式是比例量 |
| `hurtPAnti` | 抵消 hurtP 的比例 | 毒公式不读取 |
| `critP` | 暴击概率，例如 0.2 | 先减目标 critPAnit；毒公式不判暴击 |
| `critDeep` | 额外暴击增伤比例 | 与目标 critDeepAnit 相减，差值限制到 0～1，再加基础 0.5 |
| `critPAnit` | 被暴击概率减免 | 保留 Anit 拼写；不是伤害减免 |
| `critDeepAnit` | 抵消额外暴击增伤 | 不抵消基础 0.5；保留 Anit 拼写 |

### FinalAttack

| 字段 | 含义 | 使用规则 |
| --- | --- | --- |
| `dbackP` | 普通反伤比例 | 读取受击者对应物理/魔法分组，基数为实际扣血，受 nodback 限制 |
| `bloodP` | 吸血比例 | 基数为实际扣血，受 noblood 限制；当前伤害大于 1 才尝试 |
| `immunity` | 固定免伤 | 基础公式之后、合并倍率之前扣除 |
| `immunityP` | 比例免伤 | 在固定免伤后相乘，例如 0.2 减免 20% |

并不是每种 func 都读取所有 FinalAttack 字段。普通反伤读取防守单位当前属性，不因为技能表里填了 dbackP 就给施法者永久加反伤。

## 公式中的倍率

```text
合并 attack = 单位 attack × attackRate + 技能固定 attack + 技能成长 attack × level
普通基础值 = (attack - defend + hurt - hurtAnti) × (1 + max(hurtP - hurtPAnti, 0))
普通伤害 = 固定/比例免伤后的基础值 × (damageRate + 属性加成 + 暴击加成)
治疗 = 治疗基础公式 × (healRate + 相生加成 + 暴击加成)
毒基础值 = max(attack - defend + clamp(hurt - hurtAnti, 0, 0.5) × 当前目标hp, 1)
毒伤 = 毒基础值 × (poisonRate + 属性/弱点加成)
```

属性加成通常为 0 或 0.5；暴击成功时为 `0.5 + clamp(critDeep - critDeepAnit, 0, 1)`。基础公式的取整/下限、免伤、资源截断以源码为准；最终“造成了多少”取实际扣血。倍率为 0 不会屏蔽另外相加的生克或暴击加成。

相克：金克木、木克土、土克水、水克火、火克金。相生：金生水、水生木、木生火、火生土、土生金。效果标记使用 `克`、`生`、`crit`，各次计算单独保存。

## SelectParam

| 字段 | 含义 | 缺省与边界 |
| --- | --- | --- |
| `target` | 目标类型 | 必填，self/duiwei/friend/enmey；直接群体施放仅支持 friend/enmey，num > 1 配其他类型时 initSkills 中文告警 |
| `num` | 目标人数 | 缺省 1；直接施放时为总人数，大于 1 为群体，99 可覆盖全体；溅射子技能中为副目标人数，不含主目标，0 不选 |
| `sortAttr` | 排序属性键 | 缺省随机；可用 hp/mp/hpp/hplp/speed 等 getAttr 支持的键，不是嵌套路径 |
| `sortDescend` | 是否降序 | 缺省 false，只有 sortAttr 已配置时有意义 |
| `shape` | 溅射形状 | 在溅射子技能中配置，优先于 num；省略按数量；直接群体施放不使用；none 不是有效形状 |

`friend` 包含施放者自身；群体仅支持 friend/enmey，self/duiwei 用于单体。告警不改配置、不阻止注册，不代表不支持的组合会自动回退。`hpp=hp/hpMax`，`hplp=(hpMax-hp)/hpMax`。普通数值 `hp` 排序不是生命比例排序。

攻击主目标命中后才处理攻击溅射；群体施放直接取得整组目标，各目标独立命中。治疗/毒效果不套普通攻击的命中流程。明确目标非法会拒绝，只有省略目标才自动选择；普通攻击可手动守尸，PC 立即输入则拒绝死亡目标。

攻击、治疗与毒的溅射统一读取子技能 `sel.num/shape/sortAttr/sortDescend` 和 `canTarget`，副目标与当前主目标同阵营，并排除主目标。旧主技能的 `numSpread` 需迁到子技能 `num`。

目标资格由 `FightSkill.canTarget(target)` 决定，`getTargetHint` 提供拒绝原因；普通攻击、治疗、毒、无伤害技能默认选存活者，复活技能选可复活的尸体，治疗/毒同时排除禁疗/禁毒。受作用状态通过 `FightStatus` 和单位 `isForbidBeAction` 判断，石化禁止接受普攻和其他非复活技能；复活使用独立 `relife` 入口。无需再配置 `die`。

选目标、合法性与嘲讽接口，以及地图 `findDuiwei` 均接收技能实例；`getSideUnitsBySkill` 按技能查询阵营候选。没有具体技能时使用公共 `getDefaultSkill(sel?)`，缺省为敌方普攻规则，每次创建独立实例，不依赖注册表。

### 相关枚举

| 枚举 | 当前值 |
| --- | --- |
| TargetSelectEnum | self=0、duiwei=1、friend=2、enmey=3 |
| MapShapeEnum | none=0、x_line=1、y_line=2、cross=3、cross_line=4 |
| PropEnum | none=0、金=1、木=2、水=3、火=4、土=5 |

`x_line` 固定 x、沿 y 取一列；`y_line` 固定 y、沿 x 取一行，以源码坐标定义为准。

## 地图、后排与阵型

平面位置 `pos = y * nx + x`，x/y/pos 都从 0 开始。策划说的行号为 `y+1`；后排统一用 `FightMap.isBackRow`，判断为 `y+1 > ceil(ny/2)`：3×3 第 3 排、5×5 第 4/5 排。矩形地图使用高度 ny，不能把宽高混用。

阵型提供位置列表，人物位置不放在 MonsterData 模板里。对位优先查镜像列，再查其他列，各列从前往后取符合死亡过滤的单位；有一个活敌人仍可找到目标。
