## MonsterData 全部字段

| 字段 | 含义 | 缺省与规则 |
| --- | --- | --- |
| `id` | 怪物模板 ID | 0 有效，可重复实例化；不是战斗 uid |
| `name` | 继承 FightDisplay 的名称 | 必填，初始化传给客户端 |
| `character` | 继承的人物描述表键 | 可省略，0 有效；客户端 MUD 使用 |
| `attr` | 完整 FightAttr | 实例或同结构 JSON，生成时深拷贝并恢复属性类 |
| `skills` | 已学主动技能 | `[技能ID, 等级][]`，缺省空，等级 0 有效 |
| `passiveSkills` | 初始被动技能 | `[被动ID, 等级][]`，缺省空；在主动技能学习后初始化 |
| `attackSkill` | 初始替代普攻装配 | 缺省保留被动装配，0 卸下；只装配不学习 |
| `fbackSkill` | 初始反击装配 | 缺省保留被动装配，0 卸下 |
| `supportSkill` | 初始协战装配 | 缺省保留被动装配，0 卸下；需已学攻击类技能 |
| `ultimateSkill` | 初始破盾大招装配 | 缺省保留被动装配，0 卸下；不会绕过独立机会 |
| `inputSkill` | 无 AI/规则时的固定主动技能 | 缺省/0 取技能首项，再没有则普攻；烟雨原自动路径不读取旧 inputSkill |
| `ai` | 唯一决策配置 | 可省略；createAI 为每只怪物创建独立实例 |
| `rules` | 固定行为配置列表 | 可省略；多条共存，每只怪物独立计数 |

装配顺序：属性/显示 → 学习技能 → 初始化被动和附加 Buff → 模板显式装配 → 规则和 AI。显式 0 会覆盖被动装配，省略则保留。初始生命为 0 时创建死亡单位并走死亡清理。

```ts
initMonsters([{
    id: 1001,
    name: "山贼首领",
    attr: bossAttr, // 宿主提供完整FightAttr
    skills: [[101, 1], [102, 1]],
    passiveSkills: [[201, 1]],
    attackSkill: 101,
    ai: { type: "rearDoctor" },
    rules: [
        { type: "hp", lines: [{ hp: 0.7, attackRate: 0.2 }] },
        { type: "turn", every: 3, skill: 102 },
        { type: "hurt", every: 2 },
    ],
}]);
```

示例 ID 的技能、被动、Buff 需先注册，装配不会自动补学。

## AIData 全部字段

| 字段 | 含义 | 当前值 |
| --- | --- | --- |
| `type` | 决策 AI 类型 | 当前只有 `rearDoctor`，未知类型工厂报错 |

`rearDoctor` 对应 `FightAIRearDoctor`：优先普攻敌方存活的后排医生，职业用 CarerrEnum.医生。后排行号从 1 数，3×3 第 3 排、5×5 第 4/5 排；内部位置仍从 0 开始，统一由地图判断。多人使用战斗随机源选一个，只有一人不抽样；无候选或无地图不指定目标，回退原规则。嘲讽仍在执行阶段覆盖目标。

AI 不额外插入行动，它决定自己的普通行动。每只怪物只有一个 AI；`waitInput` 返回 undefined 时回退普攻。无 AI 且无规则时保留旧固定技能选择；只有规则时普通行动为普攻。

## RuleData 全部字段与分支

| 所属分支 | 字段 | 含义 | 缺省与边界 |
| --- | --- | --- | --- |
| 公共 | `prior` | 规则执行顺序 | 有限数，缺省 0；小的先，同级按添加顺序；不等于 listen 的事件优先级 |
| hp | `type` | 血轴规则标识 | 固定 `hp` |
| hp | `lines` | 血线列表 | 必填，可空，见 HpAxisLine |
| turn | `type` | 回合轴规则标识 | 固定 `turn` |
| turn | `every` | 全局回合间隔 N | 正安全整数；第 N、2N…回合前触发，每条每回合最多成功登记一次 |
| turn | `skill` | 插入行动的已学技能 ID | 正安全整数；照常检查状态、目标、CD、资源，不使用破盾 ultimate 槽 |
| turn | `pos` | 行动插入位置 | 缺省 first，见下面枚举 |
| hurt | `type` | 受伤轴规则标识 | 固定 `hurt` |
| hurt | `every` | 有效直接受伤次数 N | 正安全整数；禁止 attack 时完全不累计 |
| hurt | `skill` | 即时新攻击的已学攻击技能 ID | 可省略，省略用普攻/装配普攻；指定时需正安全整数 |

### HpAxisLine 的两个字段

| 字段 | 含义 | 校验与计算 |
| --- | --- | --- |
| `hp` | 当前生命比例血线 | 有限数 `(0,1]`；hp/hpMax 小于等于它就触发，初始生命已低也算 |
| `attackRate` | 攻击力增量比例 | 非负有限数；0.2 表示加 20%，多条相加 |

血线每条每场一次，回血、死亡、复活不刷新；新战斗重置。只改物理/魔法各攻击分组，不改治疗/毒攻击力；不会修改 attrOri。

回合轴保留普通行动，额外插入独立行动并显示在行动条。受伤轴保持即时新攻击：完整 action 后朝刚才攻击者出手，不进条、不推进输入次数、不额外收主动费用/CD；Buff、反伤、反射、分担和零伤害不累计。二者不能因为都“额外攻击”就合并成同一种调度。

## 插入位置

| InsertActionPos | 值 | 含义 |
| --- | --- | --- |
| `first` | 0 | 剩余队首，默认；连续插入按提交顺序 |
| `last` | 1 | 剩余队尾 |
| `random` | 2 | 剩余队列的随机间隙，只用 Fight.random |
| `afterSelf` | 3 | 当前/下一条自己的普通行动后；自己已行动则回退队首 |

不打断当前完整 action。速度变化重排普通行动时，afterSelf 项继续跟随其锚点。一次全局回合最多接受 64 次插入，取消不返还预算。宿主也可直接 `fight.insertAction(unit, input, pos, ctx)`；带 ctx 可与本次结算消息一起发送。行动条协议见 [客户端](./客户端与表现.md)。

## Boss 阶段切换

```ts
boss.setAI({ type: "rearDoctor" });
boss.setRules([
    { type: "turn", every: 1, skill: rageSkillId },
    { type: "hurt", every: 2 },
]);
// boss.setAI();       // 移除AI，不影响rules
// boss.clearRules();  // 清空rules，不影响AI、被动和Buff
```

`setRules` 接受 RuleData 或 FightRule 实例；新配置创建新状态，复用实例保留原计数/阶段，实例形式的 prior 默认 0。非法配置、重复实例、跨单位复用或初始化失败时保留原列表并清理本次绑定。

**已进入行动条的旧规则行动保留。** 新 AI 从下一次 waitInput 生效，不覆盖已提交指令；新周期规则从之后的回合前边界安排。移除规则后，旧受伤规则尚未执行的事件收尾回调失效。

## ZhenData 全部字段

| 字段 | 含义 | 规则 |
| --- | --- | --- |
| `id` | 阵型表 ID | 0 有效；未来宿主可在阵型旁维护其他加成，当前只消费位置 |
| `pos` | 平面位置数组 | 从 0 开始；按 ids 列表顺序分配，已用位置需非负安全整数且互不重复 |

`CreateMonsterSide(ids, zhen, allocateUid)` 接受模板 ID 列表（允许重复）、阵型 ID 和宿主 UID 分配函数。`getZhenPos` 返回副本；位置可多配，取前 N 项，少于怪物数报错。地图上界由宿主按 nx/ny 保证。双方共享 UID 分配器，避免跨阵营碰撞。
