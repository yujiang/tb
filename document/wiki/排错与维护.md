## 常用验证命令

使用 Node.js 22 或以上；当前项目依赖 Node 事件、断言和计时器，不能声称无适配运行浏览器。

```sh
npm run build
npm run test:build
npm test
npm run example
```

- 源码为 `src/`，公共入口 `src/index.ts`。
- build 输出 `bin-debug/`，包入口 `bin-debug/index.js`，类型入口 `bin-debug/index.d.ts`。
- 测试编译输出 `.test-build/`；不手工修改生成目录。
- tests/core 是自动场景，tests/report 是表现示例，tests/simple 保留用户手写流程。
- 旧 lib 实现不代表当前源码，也不当作验证通过的依据。

## 出错就停止，已有结果保留

NaN 本身不会自动抛异常；Calc 已有有限数检查，本知识库整理不新增另一套检查。运行时抛出的错误在 FightLoop 的运行/行动/输入边界捕获，默认中文 console.error，不继续后续动作或回合。仅当 `result === FightResultEnum.ongoing`（`-1`）时判 `FightResultEnum.defend=1`；已有胜负、平局或超时结果均保留。

`FightLoop.run()` 在 `finally` 中统一调用幂等的 `end()`；输入等入口也可立即结束并释放等待，不重复结算。停止时清空行动与即时技能队列，关闭普通/大招窗口，释放西游等待与计时器，执行单位监听清理。单个单位清理失败仍继续其他单位。奖惩、结束回调和最终广播异常分别记录，继续后续收尾，不改变已有结果或重试奖惩。宿主负责实际发奖幂等，库不回滚已执行的宿主操作。

底层 `Fight.processUnit/resolveAction` 等仍抛错供调用方处理。直接组合底层方法的宿主需要自己的异常边界，不能假定每个辅助函数都自动吞错。

失败动作可能已经扣费或执行部分效果；目前没有动作回滚，不把半结算当成功数据使用。错误堆栈记日志，不传给客户端，客户端按 `["end",result,winSide,runaway]` 收尾，`run()` 返回最终结果。

### FightErrorContext 全部字段

| 字段 | 含义 | 缺省 |
| --- | --- | --- |
| `fid` | 战斗 ID | 必有 |
| `seed` | 初始随机种子 | 必有；不是随机状态快照 |
| `turn` | 当前全局回合 | 必有 |
| `action` | 正在执行的独立行动 ID | 队列行动之外可能没有 |
| `actor` | 当前行动者 uid | 初始化/其他无行动阶段可能没有 |
| `input` | 当时的指令副本 | 没有明确输入时可省略；是行动意图，不保证是嘲讽后的实际目标 |

源码：[FightLoop.onError](../../src/fight/FightLoop.ts)。默认 console.error 不自动落文件。宿主覆盖日志入口即可接自己的日志系统：

```ts
loop.onError = (error, context) => {
    logger.error({ ...context, error }, "战斗异常");
};
const result = await loop.run();
```

## 玩家 fight 状态由谁解除

tb 停止内部调度并通知结束；宿主解除玩家 fight 状态。宿主在结束回调中做奖励/保存时，也应确保失败路径释放玩家状态，不能只在成功路径解除。库内状态清理不等于宿主数据库或在线玩家对象已经完成收尾。

## FightDebugData：强制战斗判定

源码：[FightDebug.ts](../../src/fight/FightDebug.ts)。从包入口导入 `setFightDebug`，接受部分字段；每次调用替换整份配置，省略或 false 均关闭，无参数或 undefined 清空。保存配置副本，调用者之后修改对象不影响已设置状态。

| 字段 | 用途 | 默认值、限制与入口 |
| --- | --- | --- |
| `hit` | 物理攻击必定命中 | 默认 false；不覆盖技能发动概率；不能闪避状态优先，hit/miss 同时开启时 miss 优先 |
| `miss` | 物理攻击必定未命中 | 默认 false；覆盖 hit 和 alwaysHit，不能闪避状态仍优先；魔法保持原规则，不进入物理命中检查 |
| `crit` | 强制暴击 | 默认 false；只覆盖原公式中具备暴击判定资格的攻击和治疗（基础公式值大于1），沿用原暴击加成；毒不判暴击 |
| `next` | 强制连击及连招子技能发动 | 默认 false；覆盖零概率，普通攻击内置连击仍只追加一段；未配置的技能不创建 |
| `spread` | 强制攻击溅射子技能发动 | 默认 false；覆盖零概率，仍需已有子技能和有效的副目标选择规则 |
| `kill` | 强制追击子技能发动 | 默认 false；覆盖零概率，仍要求真实击杀且有合法存活目标 |
| `support` | 强制协战发动 | 默认 false；覆盖零概率，仍要求合格存活队友及已学装配技能，每单位每回合次数不变 |
| `fback` | 强制普通或配置反击发动 | 默认 false；覆盖零概率，仍检查反击禁止字段、状态和目标资格，专用类仍禁止再次触发反击 |
| `hurtHpLimit` | 单次受伤的生命扣除上限 | 非负有限数，省略或 0 不限伤；正数按伤害规则向下取整，单位为生命点数。防御/盾减伤后、beforeHurt 前应用，保护分担该值；最终扣血再次限伤并遵守 minHp。技能、Buff、反伤、反射、分担均有效，治疗与 HP 费用不受影响 |

```ts
import { setFightDebug } from '@mosnpm/tb';

setFightDebug({ hit: true, crit: true, next: true, hurtHpLimit: 20 });
// 运行需要观察的战斗。
setFightDebug(); // 清空，之后恢复原随机流程。
```

配置为进程共享，不属于单场 FightData 或 FightGlobalData，也不写入客户端数据。只覆盖对应概率，不绕过死亡、封印、费用/CD、禁止字段、目标选择、协战配额或反应上限。强制的概率不抽样；目标选择和其他未强制的概率仍使用 Fight.random。调试开关会改变抽样次数与结果；测试结束应清空，避免影响后续场景。回归见 [test_fight_debug.ts](../../tests/core/test_fight_debug.ts)。

`getDebugHurtHpLimit()` 返回当前限伤值，0 为关闭。限伤在受伤前事件前生效，避免让原本不致命的调试伤害消耗不屈；最终扣血也再次受限，伤害返回值、消息、事件、仇恨、贡献、怒气以及后续吸血/反伤都使用实际扣血。普通保护对限伤后的命中分担，例如上限 20 时双方先各分配 10，再分别应用自身防御与锁血。相关回归见 [test_debug_hurt_limit.ts](../../tests/core/test_debug_hurt_limit.ts)。

## F5 查看真实异常日志

打开 [test_report_error.ts](../../tests/report/test_report_error.ts)，VS Code 选择“调试战斗异常日志”，按 F5。可以在主动抛错行或 FightLoop.onError 下断点。该示例故意抛出技能错误，展示源码堆栈，最后结果 1、队列为空、无等待输入单位。

命令行等价方式：

```sh
npm run test:build
node --enable-source-maps .test-build/tests/report/test_report_error.js
```

不是历史日志回放，而是每次运行新建的受控异常战斗。

## 从字段定位代码

1. 查 [配置总览](./配置总览.md)，进入该类型字典。
2. 在源码字段悬停看 JSDoc，确认当前默认值与特例。
3. 查该页底部自动测试，先用最小场景验证。
4. 出错日志提供 fid/seed/turn/actor/input 作为定位线索；它不包含完整快照，不能单凭日志承诺恢复战斗。

## Bug 修复约定

先新增稳定的小回归，运行确认是玩法失败而非编译/夹具错误；再修改业务代码，回归通过后跑 npm test。改示例/包入口同时验证对应命令与包导入。每个 test 调用前写中文说明，解释场景和预期，不用删除断言迎合错误实现。

## Wiki 的维护方式

- 每加一个 xxxData 字段，同时解释其用途、是否可省略、缺省、单位、范围/边界、引用关系和入口差异。
- 继承字段在公共页说明，派生类型明确链接；嵌套结构不能只留一个类型名。
- 区分代码已经校验的范围和策划应遵循的范围。
- 代码拼写有问题先记录；重命名或改变默认值单独做迁移，不混在文档整理中。
- 玩法实现变化同步测试、源码注释、字段表和示例；不要把早期讨论当作当前行为。
- 新页面在 index.md 增加链接；保持普通 Markdown，不添加仅站点插件支持的语法。以后接 VitePress 可直接复用目录与正文。
