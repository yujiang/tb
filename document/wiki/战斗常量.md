# 战斗常量

[返回目录](./index.md) · [配置总览](./配置总览.md)

源码：[FightConsts.ts](../../src/fight/FightConsts.ts)。公共入口导出 `FightConstData`、`fightConsts` 和 `initFightConsts`。

## 配置与生效时间

该文件集中管理全库共用的默认值。宿主可以从自己的常量表或 JSON 加载，再调用 `initFightConsts`。连击、追击等技能伤害倍率仍在技能配置中，不在这里重复定义。

```ts
import { initFightConsts } from '@mosnpm/tb';

// 在创建基础属性及单位之前配置；以下为示例数值，不是库内默认值。
initFightConsts({
	spHurtRate: 0.2,
	spOutputRate: 0.1,
	jpAdd: 1,
});
```

`fightConsts` 提供当前值的只读查询；更新统一经过 `initFightConsts`。每次调用只更新提供的字段，省略的字段保留当前值，显式 `0` 有效。整批字段必须是非负有限数；任何字段无效时整批不生效。

创建 `FightAttr` 时将当前常量复制到同名基础属性，原始普通对象在首次绑定单位时补齐缺省值。需要单独覆盖时设置 `unit.attrOri.jpAdd = 2` 后调用 `unit.calcAttr()`；临时效果通过 Buff/被动的 `attr/attrLevel` 修正。运行时使用 `unit.attr` 当前值。更新全局常量不会回写已有属性，因此不会影响正在进行的战斗；新建属性会使用更新后的默认值。测试应在结束时恢复模块级配置。

## FightConstData 字段字典

| 字段 | 初始默认值 | 单位、范围和用途 |
| --- | --- | --- |
| `spHurtRate` | 0 | 非负有限数，每点实际受伤增加的怒气；0 不增加，0.2 表示受伤 100 点增加 20 怒气 |
| `spOutputRate` | 0 | 非负有限数，每点实际输出伤害或实际治疗增加的怒气；伤害与治疗共用此倍率，0 不增加 |
| `jpAdd` | 1 | 非负有限数，每次有效行动条行动结束时，单位默认增加的集气点数；允许小数，0 不增加 |

这里的怒气倍率不限定在 0～1，实际增加量仍受对应资源上限约束。字段类型在完整配置中必填，初始化入口接受 `Partial<FightConstData>`。资源上限、实际伤害/治疗规则及行动条边界见[属性与选目标](./属性与选目标.md)。
