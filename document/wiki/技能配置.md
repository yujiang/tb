## SkillData 每个字段

| 字段 | 含义 | 缺省、单位与注意 |
| --- | --- | --- |
| `id` | 主动技能表 ID | 非零；同 ID 后注册覆盖旧表项 |
| `name` | 技能名称 | 必填；表现端从本地表读取 |
| `desc` | 技能说明 | 可省略，不参与结算 |
| `nomove` | 是否原地施法，0/1 | 省略或 0 需要移动，1 不需要移动；缠绕禁止 move，只允许 1。装配普攻、子技能、反击和协战各读自身配置 |
| `magic` | 是否魔法攻击 | true 取魔法分组且不做物理命中；false 取物理分组 |
| `alwaysHit` | 是否必中 | 缺省 false；true 跳过物理命中，不受闪避影响，也不抽取命中随机数；不改变 rand 发动概率，魔法原本不做物理命中 |
| `skillProp` | 技能五行 | 可省略；攻击/毒用 weaponProp，治疗用 charProp；显式 none 不回退 |
| `rand` | 发动概率 | 类型必填，读取时缺省 1；0～1，主攻击及 heal/poison/relife/nohurt 一般建议 1，只提醒不改值；主动单体每次施放判一次，群体整组判一次，失败仍支付费用/CD；不是命中率，周期 Buff 不走主动判定 |
| `sel` | 目标规则 | 主动技能需有效 SelectParam，详见属性与选目标 |
| `cost` | 根主动技能 HP/MP 费用 | 可省略，见下表；子技能、装配普攻不重复收主动费用 |
| `cd` | 主动技能全局回合冷却 | 缺省 0，非负安全整数；第 t 回合施放，t+cd 可再用 |
| `func` | 效果函数 | normal/heal/poison/relife/nohurt；省略或未知名字回退 normal |
| `attack` | BaseAttack 固定增量 | 可填 {}；与对应单位/阶段属性合并 |
| `final` | FinalAttack 固定增量 | 可填 {}；不同公式读取的字段不同 |
| `attackLevel` | 每级 BaseAttack 增量 | 缺省无成长，乘技能等级；0 级仍保留固定加成 |
| `finalLevel` | 每级 FinalAttack 增量 | 缺省无成长，乘技能等级 |
| `attackRate` | 单位 attack 倍率 | 非负有限数，缺省 1；只缩放单位攻击数值，不缩放命中等字段 |
| `damageRate` | 普通攻击伤害倍率 | 非负有限数，缺省 1；与属性/暴击加成相加，不控制治疗/毒伤 |
| `healRate` | 治疗倍率或复活比例 | 非负有限数，缺省 1；relife 直接恢复 floor(目标 hpMax × healRate) |
| `poisonRate` | 毒伤倍率 | 非负有限数，缺省 1；与属性/弱点加成相加 |
| `spread` | 溅射子技能 ID | 缺省无配置溅射；从子技能 sel.num/shape 与 canTarget 选副目标，使用 spread 阶段 |
| `next` | 连击子技能 ID | 重新按子技能 sel 选目标，使用 next 阶段 |
| `combo` | 连招子技能 ID | 继承实际主目标；死亡停止；与 next 同填时 next 优先 |
| `kill` | 击杀追击子技能 ID | 重新选目标，使用 kill 阶段 |
| `addBuff` | 给目标附加 Buff | `[Buff ID, 等级, 概率][]`；在命中/效果阶段执行，不是给自身 |
| `rmeoveBuff` | 按 ID 驱散 | `[Buff ID, 概率][]`；优先于 removeBuffTag |
| `removeBuffTag` | 按标签驱散 | 可省略；先筛选强度允许且可驱散的 Buff |
| `removeBuffNum` | 按标签驱散数量 | 正数限制数量；缺省或 <=0 取所有合格候选，少选时随机 |
| `afterSelfBuff` | 该段施放后的自身 Buff | `[Buff ID, 等级, 概率][]`；后续链返回后加，未发动不加，攻击未命中仍加 |
| `power` | 技能驱散强度 | 缺省取技能等级，显式 0 有效；不赋给所添加 Buff 的 power |
| `attackSkill` | 给施放者装配替代普攻 | 只装配不学习；缺省不变，0 卸下 |
| `fbackSkill` | 给施放者装配反击 | 只装配不学习；缺省不变，当前效果入口忽略 0 |
| `supportSkill` | 给施放者装配协战 | 只装配不学习；缺省不变，当前效果入口忽略 0 |
| `ultimateSkill` | 给施放者装配破盾大招 | 只装配不学习；缺省不变，0 卸下；由自身破盾后自动触发 |
| `tags` | 数据分类 | 可省略，不控制程序中的固定禁止行为 |
| `noblood` | 禁止本次攻击吸血 | 缺省 false；不禁止不等于一定吸血 |
| `nodback` | 禁止本次攻击受到普通反伤 | 缺省 false；不控制 BuffReflect 反射 |
| `nofback` | 禁止本次攻击触发对方反击 | 缺省 false；专用反击类仍不会无限互反 |
| `nosupport` | 禁止召唤队友协战 | 缺省 false；仍需合格协战者与其发动概率 |
| `noprotect` | 禁止保护分担本次伤害 | 缺省 false；不移除保护 Buff |

### SkillCost

| 字段 | 含义 | 规则 |
| --- | --- | --- |
| `hp` | 生命点数费用 | 省略/0 不扣，建议非负；玩家/召唤物付费后必须仍有生命。整笔费用完成后发 hp 事件，来源为本人，不发 hurt、不产怒气 |
| `mp` | 法力点数费用 | 省略/0 不扣，建议非负；可刚好用完 |
| `sp` | 怒气点数费用 | 非负有限数，省略/0 不扣；可刚好用完 |
| `jp` | 集气点数费用 | 非负有限数，省略/0 不扣；可刚好用完；全局 jiqi 关闭时忽略校验和扣费，不发送 costJp |

四种费用可以同时配置，例如 `cost: { mp: 10, sp: 50, jp: 3 }`。玩家/召唤物先检查全部资源，再整笔支付；任一资源不足时不扣其他资源。根主动技能只支付一次，内部子技能不重复扣费。HP 费用直接扣除，不作为伤害或治疗，不产生怒气。新资源及增长规则见[属性与选目标](./属性与选目标.md)。

生命费用发生真实扣血后，在所有 HP/MP/SP/JP 费用及消息写入完成后、技能效果结算前，通知 `hp(unit, ctx, unit, previousHp, currentHp)`。血线监听可据此立即改变属性，本次技能会使用新属性；监听中重算属性也不会漏扣其他资源。预检、费用不足或零生命费用不发 hp；费用不发 beforeHurt/hurt，也不计受伤次数、伤害贡献或受伤/输出怒气。客户端仍只消费原有 costHp 等费用消息。

怪物沿用不耗资源的实现。主动技能正式尝试时开始 CD，未发动/未命中也消耗 CD；费用不足、无目标则不开始。装配普攻、连招/追击/反击/协战不重复收取主动费用/CD。

## func 差异

- `normal`：普通攻击管线，发动后进行物理命中（若非魔法）、伤害、效果与反应链。
- `heal`：治疗；受禁疗与生命上限影响。
- `poison`：毒伤；受禁毒影响，不判暴击。
- `relife`：目标必须死亡且未禁复活，用 healRate × hpMax 恢复，由 canTarget 自动筛选，无需 die 配置。
- `nohurt`：处理 Buff 增删和技能装配，没有直接伤害。

单体 `heal/poison/relife/nohurt` 在费用检查、扣费和启动 CD 后，执行效果前统一判一次 `rand`；群体仍在外层对整组判一次，不按目标重复判定。0 必定不发动，1 必定发动，两者均不消耗概率随机数。发动失败发送 `skillFailed`，不治疗、不扣血、不复活、不执行效果或 `afterSelfBuff`，但仍消耗费用和 CD；被有效嘲讽约束的单体行动仍消耗该次嘲讽。非攻击类发动成功后的自身 Buff 仍按函数成功返回处理。周期 Buff 的 heal/poison 不走主动施放概率检查。

## 群体与溅射

```ts
// 直接群攻，总共最多99人；禁止互动是填表建议。
sel: { target: TargetSelectEnum.enemy, num: 99 },
nosupport: true,
noprotect: true,
```

```ts
// 主技能：单体命中后触发溅射。
sel: { target: TargetSelectEnum.enemy },
spread: spreadSkillId,

// spreadSkillId 对应的子技能：另外两人，不含主目标。
sel: { target: TargetSelectEnum.enemy, num: 2 },
```

群攻每个目标复用单目标流程；溅射只执行子技能的一次伤害/属性效果，不为每个副目标展开完整 next/kill/fback 链。两者保持不同流程，不为了合并循环强行统一。

攻击、治疗和毒的溅射都读取子技能的 sel 与 canTarget；人数、形状和排序应写在子技能上。旧主表 numSpread 迁移为子技能 num。治疗/毒仍由 AttrSkill 处理，没有套用普通攻击的物理命中/发动流程。

## 连击、连招与追击

`next` 重新选择目标；`combo` 固定继承上一段实际主目标；`kill` 在击杀后追击。子技能可继续配置链，整条动作共享反应预算。

连招中间段不触发普通反击和反伤；成功到最后一段、双方仍存活且连招未被死亡打断时，按末段字段结算累计实际扣血对应的反伤，再尝试反击。中途未发动、未命中或死亡不补算。吸血按段处理，溅射/其他动作的伤害不混入主目标累计。

三段倍率 0.4、0.7、1.0 可以得到总和 2.1；技能结束给自身加休息 Buff，休息通常用 afterTurn + lastTurn=2。完整示例见 [原技能说明](../技能.md)。

## 填表建议与 initSkills 告警

以下是表现建议，不是强制运行限制：

- 单一主目标可以协战、被保护；群攻和溅射子技能建议 `nosupport: true, noprotect: true`，保持场面清楚。
- 协战技能及后续攻击链建议 `nofback: true, nodback: true`，避免演出反复穿插。
- 大招建议 `noprotect: true`，主攻击及 heal/poison/relife/nohurt 一般建议 `rand: 1`；仍允许按玩法配置其他概率，只告警、不改值。

`initSkills` 注册整批后中文 warn，带技能名/ID/字段；还会提醒 num > 1 时 sel.target 不是 friend/enemy（群体仅支持这两种目标类型）、next/combo 同填及协战 func 不符。识别来自当前技能表引用；被动、怪物表或运行时才装配的角色，单靠技能表不能完整识别。不改配置、不阻止注册。

## 物理与魔法致死配置

`createLethalSkillData(id, magic = false)` 返回独立 `SkillData`，由宿主分配非零 ID、`initSkills` 注册并让单位学习。缺省物理版，第二项 true 为魔法版；两者 `attackRate: 0, attack: { attack: 99999 }, rand: 1, alwaysHit: true`，使用 normal 技能管线。固定的是攻击力，仍正常经过防御、免伤、防御指令、盾、保护、反伤和不屈等效果，并非直接强制死亡。
