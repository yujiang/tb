## SkillData 每个字段

| 字段 | 含义 | 缺省、单位与注意 |
| --- | --- | --- |
| `id` | 主动技能表 ID | 非零；同 ID 后注册覆盖旧表项 |
| `name` | 技能名称 | 必填；表现端从本地表读取 |
| `desc` | 技能说明 | 可省略，不参与结算 |
| `action` | MUD出招文本 | 可省略；字符串或候选字符串数组，跳过空白并按展示次数轮换。支持$N施放者、$n目标、$w本人display.weaponName、$l表现部位及{技能}等占位符；优先于客户端出手文本，无配置才回退，不影响战斗随机、命中或伤害 |
| `nomove` | 是否原地施法，0/1 | 省略或 0 需要移动，1 不需要移动；缠绕禁止 move，只允许 1。装配普攻、子技能、反击和协战各读自身配置 |
| `magic` | 是否魔法攻击 | true 取魔法分组且不做物理命中；false 取物理分组 |
| `alwaysHit` | 是否必中 | 缺省 false；true 跳过物理命中，不受闪避影响，也不抽取命中随机数；不改变 rand 发动概率，魔法原本不做物理命中 |
| `skillProp` | 技能五行 | 可省略；攻击/毒用 weaponProp，治疗用 charProp；显式 none 不回退 |
| `rand` | 发动概率 | 类型必填，读取时缺省 1；0～1，主攻击及 heal/poison/relife/nohurt/observe/entrust/mimic 一般建议 1，只提醒不改值；主动单体每次施放判一次，群体整组判一次，失败仍支付费用/CD；不是命中率，周期 Buff 不走主动判定 |
| `sel` | 目标规则 | 主动技能需有效 SelectParam，详见属性与选目标 |
| `cost` | 根主动技能 HP/MP 费用 | 可省略，见下表；子技能、装配普攻不重复收主动费用 |
| `cd` | 主动技能全局回合冷却 | 缺省 0，非负安全整数；第 t 回合施放，t+cd 可再用 |
| `func` | 效果函数 | normal/heal/poison/relife/nohurt/observe/entrust/mimic；省略或未知名字回退 normal。entrust仅PC托付当前行动。mimic配sel.target=self保存全局最近攻击，配any按指定单位复制最新实际指令（含防御等）；模仿只结算本身费用/CD，回放其他校验不变 |
| `attack` | BaseAttack 固定增量 | 可填 {}；与对应单位/阶段属性合并 |
| `final` | FinalAttack 固定增量 | 可填 {}；不同公式读取的字段不同 |
| `attackLevel` | 每级 BaseAttack 增量 | 缺省无成长，乘技能等级；0 级仍保留固定加成 |
| `finalLevel` | 每级 FinalAttack 增量 | 缺省无成长，乘技能等级 |
| `bloodP` | 本次技能固定吸血比例 | 可省略；非负有限数，1为100%、0明确不吸血，可大于1。配置时覆盖合并后的吸血比例，不随finalLevel成长；省略才沿用人物对应分组与技能final/finalLevel合并后的bloodP。noblood仍优先禁止，各子技能独立读取 |
| `attackRate` | 单位 attack 倍率 | 非负有限数，缺省 1；只缩放单位攻击数值，不缩放命中等字段 |
| `damageRate` | 普通攻击伤害倍率 | 非负有限数，缺省 1；与属性/暴击加成相加，不控制治疗/毒伤 |
| `healRate` | 治疗倍率或复活比例 | 非负有限数，缺省 1；relife 直接恢复 floor(目标 hpMax × healRate) |
| `poisonRate` | 毒伤倍率 | 非负有限数，缺省 1；与属性/弱点加成相加 |
| `spread` | 溅射子技能 ID | 缺省无配置溅射；从子技能 sel.num/shape 与 canTarget 选副目标，使用 spread 阶段 |
| `next` | 连击子技能 ID | 重新按子技能 sel 选目标，使用 next 阶段 |
| `combo` | 连招子技能 ID | 继承实际主目标；死亡停止；与 next 同填时 next 优先 |
| `kill` | 击杀追击子技能 ID | 重新选目标，使用 kill 阶段 |
| `addBuff` | 给目标附加 Buff | `[Buff ID, 等级, 概率][]`；在命中/效果阶段执行，不是给自身 |
| `rmeoveBuff` | 按 ID 驱散 | `[Buff ID, 概率][]`；优先于 removeBuffTag |
| `removeBuffTag` | 按标签驱散 | 可省略；先筛选强度允许且可驱散的 Buff |
| `removeBuffNum` | 按标签驱散数量 | 正数限制数量；缺省或 <=0 取所有合格候选，少选时随机 |
| `afterSelfBuff` | 该段施放后的自身 Buff | `[Buff ID, 等级, 概率][]`；后续链返回后加，未发动不加，攻击未命中仍加 |
| `power` | 技能驱散强度 | 缺省取技能等级，显式 0 有效；不赋给所添加 Buff 的 power |
| `attackSkill` | 给施放者装配替代普攻 | 只装配不学习；缺省不变，0 卸下 |
| `fbackSkill` | 给施放者装配反击 | 只装配不学习；缺省不变，当前效果入口忽略 0 |
| `supportSkill` | 给施放者装配协战 | 只装配不学习；必须是已注册的normal技能（func省略同normal），否则装配时断言失败；未学时不参与协战；缺省不变，当前效果入口忽略0 |
| `ultimateSkill` | 给施放者装配破盾大招 | 只装配不学习；缺省不变，0 卸下；由自身破盾后自动触发 |
| `tags` | 数据分类 | 可省略，不控制程序中的固定禁止行为 |
| `noblood` | 禁止本次攻击吸血 | 缺省 false；不禁止不等于一定吸血 |
| `nodback` | 禁止本次攻击受到普通反伤 | 缺省 false；不控制 BuffReflect 反射 |
| `nofback` | 禁止本次攻击触发对方反击 | 缺省 false；专用反击类仍不会无限互反 |
| `fbackOnBlock` | 装配为fbackSkill时格挡必反击 | 缺省false；当前受击段格挡时仅跳过该反击技能自身rand，未格挡仍用原rand。不绕过来袭nofback、连招末段、实际伤害>1及行动状态等检查；只看末段格挡，不累计前两段 |
| `nosupport` | 禁止召唤队友协战 | 缺省 false；仍需合格协战者与其发动概率 |
| `noprotect` | 禁止保护分担本次伤害 | 缺省 false；不移除保护 Buff |

### 托付当前行动位

`func: 'entrust'` 配置 `sel: { target: TargetSelectEnum.friend }`，`rand` 通常填1，`nomove: 1` 表示可原地托付。A托付B时，`A → C → B` 变为 `B → C → B`，复用A行动ID，受托位不参与速度重排，B原行动保留。B在受托位重新等待输入、推进自己的inputTurn并结算对应Buff，技能和费用由B的新指令决定。托付本身不额外推动集气，B完成该行动才推动。可以继续托付，每回合插入/托付共用64次上限；目标不能为自己、敌方、死亡或离场单位，ID为0合法。只允许PC普通行动，西游/烟雨及固定指令插入不支持；输入、执行与直接skillFunc调用均检查PC能力。示例见 [托付回归](../../tests/core/skill/test_entrust.ts)。

### 模仿最近一次攻击

`func: 'mimic'` 建议配置 `sel: { target: TargetSelectEnum.self }`、`magic: true`、`nomove: 1`、`rand: 1`，施放者不另选原攻击目标。记录每场最近一次普通攻击（含none默认攻击、装配普攻）或normal主动技能；防御、保护、治疗、托付及其他非攻击func不会覆盖。例如A攻击、B保护、C模仿，C仍使用A的攻击。模仿完成后的攻击也可继续被模仿，新战斗清空记录。

记录内容为 `FightInput` 副本（cmd/skill/target）及原技能配置、等级，不保存上次结算的目标集合；调用者随后修改指令不会影响记录。攻击力及属性使用模仿者当前值，原技能等级保留。回放时去掉旧turn与内部ultimate标记，复用 `prepareActionInput`、普通攻击/技能的校验及选目标入口：显式目标保留原意图，未指定时重新自动选择，死亡/离场等失效目标按公共规则回退，群攻按当前场面重新选择；无合法目标才拒绝。嘲讽等正常约束仍可重定向单体，显式普攻不因默认对位而被误拒绝。连击、追击、反击、协战等仍走通用攻击管线，不单独成为记录；完整动作后的自动破盾攻击大招可以更新记录。

被模仿技能不要求已学，回放指令设置内部 `ignoreCostCD: true`，由公共校验/执行流程免除全部HP/MP/SP/JP费用和CD检查/启动，不改变原技能已有CD。只检查和结算模仿技能自身的费用/CD；存活、移动、封印、阵营、目标资格、概率/命中及反应上限等其他规则不变。技能副本保留原表的cost/cd配置；临时技能只提供原等级的查询能力，不再隐式免CD，不写入已学列表，已学同ID技能的实例/等级保持不变，结算异常也撤销临时能力。客户端不可主动提交ignoreCostCD=true，详见 [指令字段](./战斗与输入.md)。PC预检原攻击资格；整轮收指令的网游在执行时按当时最新攻击记录复验。参见 [模仿测试](../../tests/core/skill/test_mimic.ts)。

```ts
{ id: 102, name: '模仿', func: 'mimic', magic: true, nomove: 1, rand: 1,
  sel: { target: TargetSelectEnum.self }, attack: {}, final: {}, cost: { mp: 5 } }
```

### 高级模仿指定单位

高级模仿仍用 `func: 'mimic'`，配置 `sel: { target: TargetSelectEnum.any }` 选择任意“行动来源”，双方单位均可；sel.num省略或1，不能群体选择多个来源。输入target为来源UID，0有效；未指定时按排序/随机机制从可回放记录中自动选择。普通模仿配置self，使用全局最近攻击，不选择来源。来源必须实际执行过根行动，提交过输入、仍在等待或只有反击等子反应不算。来源死亡/石化不影响只读记录，在场才可选，新战斗清空全部记录。

每个单位记录最近实际指令，支持普攻、normal技能、治疗、防御、保护、托付等，保留原技能等级。普通模仿仍独立读取全局最近攻击，防御等不会覆盖它。模仿后为施放者记录实际回放的指令，外层模仿技能不覆盖，避免递归模仿。己方来源保留原target；敌方来源的attack/none/skill清空原target，按模仿者当前阵营及技能规则重选。其他指令复用原字段，仍需满足保护不能指向自身、召唤物控制权、逃跑开关等检查。

只结算高级模仿自己的费用/CD，回放设置内部ignoreCostCD；原技能可未学会，已有CD不影响且不改写，其他状态与目标检查照常。普通指令与技能均复用Fight执行入口及同一ctx，不另建反应预算；复制托付仅PC普通行动可用，仍消耗当前行动位。见 [高级模仿测试](../../tests/core/skill/test_mimic_any.ts)。

### SkillCost

| 字段 | 含义 | 规则 |
| --- | --- | --- |
| `hp` | 生命点数费用 | 省略/0 不扣，建议非负；玩家/召唤物付费后必须仍有生命。整笔费用完成后发 hp 事件，来源为本人，不发 hurt、不产怒气 |
| `mp` | 法力点数费用 | 省略/0 不扣，建议非负；可刚好用完 |
| `sp` | 怒气点数费用 | 非负有限数，省略/0 不扣；可刚好用完 |
| `jp` | 集气点数费用 | 非负有限数，省略/0 不扣；可刚好用完；全局 jiqi 关闭时忽略校验和扣费，不发送 costJp |

四种费用可以同时配置，例如 `cost: { mp: 10, sp: 50, jp: 3 }`。玩家/召唤物先检查全部资源，再整笔支付；任一资源不足时不扣其他资源。根主动技能只支付一次，内部子技能不重复扣费。HP 费用直接扣除，不作为伤害或治疗，不产生怒气。新资源及增长规则见[属性与选目标](./属性与选目标.md)。

生命费用发生真实扣血后，在所有 HP/MP/SP/JP 费用及消息写入完成后、技能效果结算前，通知 `hp(unit, ctx, unit, previousHp, currentHp)`。血线监听可据此立即改变属性，本次技能会使用新属性；监听中重算属性也不会漏扣其他资源。预检、费用不足或零生命费用不发 hp；费用不发 beforeHurt/hurt，也不计受伤次数、伤害贡献或受伤/输出怒气。客户端仍只消费原有 costHp 等费用消息。

怪物沿用不耗资源的实现。主动技能正式尝试时开始 CD，未发动/未命中也消耗 CD；费用不足、无目标则不开始。装配普攻、连招/追击/反击/协战不重复收取主动费用/CD。

## func 差异

- `normal`：普通攻击管线，发动后进行物理命中（若非魔法）、伤害、效果与反应链。
- `heal`：治疗；受禁疗与生命上限影响。
- `poison`：毒伤；受禁毒影响，不判暴击。
- `relife`：目标必须死亡且未禁复活，用 healRate × hpMax 恢复，由 canTarget 自动筛选，无需 die 配置。
- `nohurt`：处理 Buff 增删和技能装配，没有直接伤害。
- `observe`：观察目标，揭示其全部五行和兵器弱点，不扣血或扣盾。单体观察填 `sel: { target: TargetSelectEnum.enemy }`，通常填 `rand: 1`。复用普通技能费用和冷却，每次成功观察发送一次 `weaknessAll`，同步完整列表（含已揭示项）。

单体 `heal/poison/relife/nohurt/observe` 在费用检查、扣费和启动 CD 后，执行效果前统一判一次 `rand`；群体仍在外层对整组判一次，不按目标重复判定。0 必定不发动，1 必定发动，两者均不消耗概率随机数。发动失败发送 `skillFailed`，不治疗、不扣血、不复活、不执行效果或 `afterSelfBuff`，但仍消耗费用和 CD；被有效嘲讽约束的单体行动仍消耗该次嘲讽。非攻击类发动成功后的自身 Buff 仍按函数成功返回处理。周期 Buff 的 heal/poison 不走主动施放概率检查。

## 群体与溅射

```ts
// 直接群攻，总共最多99人；禁止互动是填表建议。
sel: { target: TargetSelectEnum.enemy, num: 99 },
nosupport: true,
noprotect: true,
```

```ts
// 主技能：单体命中后触发溅射。
sel: { target: TargetSelectEnum.enemy },
spread: spreadSkillId,

// spreadSkillId 对应的子技能：另外两人，不含主目标。
sel: { target: TargetSelectEnum.enemy, num: 2 },
```

群攻每个目标复用单目标流程；溅射只执行子技能的一次伤害/属性效果，不为每个副目标展开完整 next/kill/fback 链。两者保持不同流程，不为了合并循环强行统一。

攻击、治疗和毒的溅射都读取子技能的 sel 与 canTarget；人数、形状和排序应写在子技能上。旧主表 numSpread 迁移为子技能 num。治疗/毒仍由 AttrSkill 处理，没有套用普通攻击的物理命中/发动流程。

## 连击、连招与追击

`next` 重新选择目标；`combo` 固定继承上一段实际主目标；`kill` 在击杀后追击。子技能可继续配置链，整条动作共享反应预算。

连招中间段不触发普通反击和反伤；成功到最后一段、双方仍存活且连招未被死亡打断时，按末段字段结算累计实际扣血对应的反伤，再尝试反击。中途未发动、未命中或死亡不补算。吸血按段处理，溅射/其他动作的伤害不混入主目标累计。

三段倍率 0.4、0.7、1.0 可以得到总和 2.1；技能结束给自身加休息 Buff，休息通常用 afterTurn + lastTurn=2。完整示例见 [原技能说明](../技能.md)。

## 填表建议与 initSkills 告警

以下是表现建议，不是强制运行限制：

- 单一主目标可以协战、被保护；群攻和溅射子技能建议 `nosupport: true, noprotect: true`，保持场面清楚。
- 协战技能及后续攻击链建议 `nofback: true, nodback: true`，避免演出反复穿插。
- 大招建议 `noprotect: true`，主攻击及 heal/poison/relife/nohurt/observe 一般建议 `rand: 1`；仍允许按玩法配置其他概率，只告警、不改值。

`initSkills` 注册整批后中文 warn，带技能名/ID/字段；还会提醒 num > 1 时 sel.target 不是 friend/enemy/any（己方、敌方或任意阵营）、next/combo 同填及协战 func 不符。识别来自当前技能表引用；被动、怪物表或运行时才装配的角色，单靠技能表不能完整识别。不改配置、不阻止注册。

验证：[字段告警](../../tests/core/skill/test_skill_config.ts)、[群体与溅射](../../tests/core/skill/test_multi.ts)、[连招](../../tests/core/skill/test_combo.ts)、[协战](../../tests/core/skill/test_skill_support.ts)。

## 物理与魔法致死配置

`createLethalSkillData(id, magic = false)` 返回独立 `SkillData`，由宿主分配非零 ID、`initSkills` 注册并让单位学习。缺省物理版，第二项 true 为魔法版；两者 `attackRate: 0, attack: { attack: 999999 }, rand: 1, alwaysHit: true`，使用 normal 技能管线。固定的是攻击力，仍正常经过防御、免伤、防御指令、盾、保护、反伤和不屈等效果，并非直接强制死亡。

## 固定吸血与吸血属性

技能配置 `bloodP: 1` 表示本次固定吸收实际扣血的100%；配置0表示不吸血，不再叠加人物或技能final中的吸血比例。省略bloodP时，通过 `skill.getBloodP()`读取原管线合并后的final.bloodP，保留人物吸血、技能固定加成和等级成长。`final.bloodP: 0.1`仍然只是+10%加成，两个字段职责分开。固定比例不应用finalLevel成长，各主/子技能独立取值，noblood仍可禁止吸血。原有伤害大于1才尝试吸血的条件不变。

统一结算调用 `tryBlood(attacker, defender, magic, damage, skill.getBloodP(), ctx)`，ctx始终在最后；直接调用且需要回退人物属性时，bloodP显式传undefined。回血仍通过onHeal处理上限、治疗前事件和资源消息。

## 单位技能使用次数

`unit.getSkillUseCount(skillId)` 查询本场该技能ID累计实际发动次数；`unit.getSkillTypeUseCount(type)` 查询本场该出手类型的次数，均默认0。`SkillUseType` 为 `normal`（普通行动的普攻/主动技能）、`support`（协战）、`fback`（反击）、`next`（连击）、`combo`（连招）、`kill`（追击）、`spread`（溅射）、`trap`（陷阱）。默认普攻及内置反击等没有表ID的攻击统一使用ID0，按类型查询可区分。相同ID经不同出手类型发动时，技能ID总数累计，类型总数分别累计。

通过校验并通过发动概率后、命中和效果前增加次数；发动失败及费用/CD/状态/目标校验失败不计，未命中仍计，被陷阱中断的已发动攻击也计。群攻按整次施放计一次，一次溅射有多个副目标也只计一次；攻击/治疗/毒等主动技能均统计，连招等子技能独立统计，模仿本身与实际回放分别统计。Buff周期回血/毒不是新的单位技能施放，不计数。

同步事件为 `useSkill(unit, ctx, skill, type, skillCount, typeCount)`，发出时两种计数均已更新，包含当前这次。Buff可通过此事件查询次数，或在攻击事件中修正本次技能计算数值；不要修改 `skill.getXls()` 中的注册配置。回合、死亡复活、改装不重置次数；同一Fight内重绑不重置，绑定不同Fight清零。计数只保存在服务端单位上，不新增输入字段或客户端协议。
